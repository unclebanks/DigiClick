# Local AI documentation

This folder is intended as a compact reference for a local coding model working on this project.

## Files in this folder
- codebase-map.md: a quick map of the app structure and key responsibilities.
- implemented-features.md: a detailed summary of the gameplay systems already implemented.
- feature-workflow.md: a simple workflow for implementing features safely.

## How to use this with a local model
1. Read AGENTS.md first.
2. Open the relevant files in src based on the feature request.
3. Make small, incremental edits.
4. Verify with the project commands before finishing.

## Suggested model behavior
For a 7B or 14B Qwen-style coding model, prefer:
- short, explicit instructions
- one feature at a time
- minimal edits with clear intent
- verification after each change
